### 年度統計表金額來源更新（2026-05-19）
- **原邏輯**：從主工作簿月份分頁（一月、二月…）讀取每日金額（僅停車金額）
- **新邏輯**：從月份 Excel（`月份資料\2026年XX月.xlsx`）每日分頁（`YYYY-MM-DD`）讀取
  - 從最底列往上掃描，找最後一個 B欄="合計" 的列，取 D欄金額

- 套用方式：執行 `python import.py rebuild_stats`

### rebuild 後發票資料消失 bug 修正（2026-05-19）
- **問題**：每次執行 `rebuild` 會從頭重建每日分頁，發票區塊被清除
- **原因**：`rebuild_monthly()` 只讀 `parking_*.xlsx`，不含發票資料
- **修正**：`rebuild_monthly()` 建完每日分頁後，自動檢查本機是否有對應的 `invoice_YYYY-MM-DD.xlsx`，有則一併寫入發票區塊
- **效果**：之後無論執行幾次 `rebuild`，本機已儲存的發票資料都不會消失

### rebuild_stats 指令新增（2026-05-19）
- **問題**：`rebuild_monthly()` 建立每日分頁時尚無發票資料，統計分頁讀不到發票合計
- **解法**：新增獨立函數 `rebuild_stats()`，專門重建所有月份 Excel 的年度收入統計分頁
- `rebuild_invoices()` 執行完後會自動呼叫 `rebuild_stats()`，確保統計永遠是最新合計
- 新增指令：`python import.py rebuild_stats`

## 七、重要技術細節

### 登入問題修正
- 使用 `page.expect_navigation(timeout=15000, wait_until="networkidle")` 包住 click，而非先 click 再 wait_for_load_state
- 這是 ASP.NET WebForms redirect 登入的正確處理方式

### Dialog 處理
- `page.on("dialog", lambda d: d.accept())` 必須在登入成功後、進入抓取迴圈前**只註冊一次**
- 放在迴圈內會因多次註冊而出錯

### 防 OneDrive 衝突
- 先存到 `C:\temp\parking\month_save.xlsx`（暫存）
- 再用 `shutil.copy2()` 複製到目標路徑
- 若 PermissionError（Excel 開啟中），最多重試 6 次，每次等 10 秒

### clean_invoice_sections bug 修正
- 刪除起始列應為 `inv_start - 1`（空白列）而非 `inv_start - 2`（會連合計列一起刪）

### 鎖定檔過濾
- glob 結果需過濾掉 `~$` 開頭的 Excel 暫存鎖定檔：
  ```python
  [f for f in files if not os.path.basename(f).startswith("~$")]
  ```

## 九、自動補跑機制（2026-05-19 深夜）

### 問題
每天 8:00 排程若電腦未開機則不執行，停機多天會造成資料缺漏。

### 解法

#### 1. 工作排程器設定「開機補跑」
- `StartWhenAvailable = true`
- 電腦開機後若排程時間已過，立即執行一次

#### 2. catch_up.py 自動偵測缺漏天數逐日補跑
- 讀取 `last_run.txt` 記錄的上次執行日期
- 計算「上次執行隔天 ~ 昨天」所有缺漏日期
- 逐日依序呼叫 `run(date_str)`，每天完整執行：
  - 下載停車資料 → 更新 Excel
  - 查詢電子發票 → 寫入分頁
  - 截圖存至桌面「每日圖檔」
  - 寄信（有設定 App Password 時）
- 每天成功後更新 `last_run.txt`

#### 3. run_daily.bat 改為執行 catch_up.py
```bat
@echo off
cd /d C:\temp\parking
"C:\Users\gjsky\AppData\Local\Programs\Python\Python312\python.exe" catch_up.py >> C:\temp\parking\run_log.txt 2>&1
```

### 效果
| 情況 | 結果 |
|------|------|

| 停機 1 天 | 開機後自動補跑 1 天 |
| 停機 N 天 | 開機後自動逐日補跑 N 天 |
