# 磐鈺雲華商業停車場 自動化系統 安裝說明

## 一、安裝 Python 3.12
https://python.org/downloads
安裝時勾選「Add Python to PATH」

## 二、安裝套件
```
pip install playwright openpyxl ddddocr pillow
playwright install chromium
```

## 三、建立工作資料夾
```
mkdir C:\temp\parking
```

## 四、複製程式檔案
將以下檔案複製到 `C:\temp\parking\`：
- `import.py`
- `catch_up.py`
- `run_daily.bat`

## 五、建立設定檔

**`C:\temp\parking\config.txt`**（參考 config.example.txt）
填入 停車場營業紀錄.xlsx 的完整路徑：
```
C:\Users\你的帳號\...\停車場營業紀錄.xlsx
```

**`C:\temp\parking\gmail_config.txt`**（參考 gmail_config.example.txt）
第1行：寄件 Gmail 帳號
第2行：Gmail 應用程式密碼（16碼，含空格）

## 六、複製 Excel 主檔
將 `每日現金支付統計\停車場營業紀錄.xlsx` 放到目標路徑。

## 七、設定 Windows 工作排程器
執行以下 PowerShell（以系統管理員身分）：
```powershell
$action   = New-ScheduledTaskAction -Execute "C:\temp\parking\run_daily.bat"
$trigger  = New-ScheduledTaskTrigger -Daily -At "08:00"
$settings = New-ScheduledTaskSettingsSet -StartWhenAvailable -RunOnlyIfNetworkAvailable -DontStopIfGoingOnBatteries -AllowStartIfOnBatteries
$principal = New-ScheduledTaskPrincipal -UserId "$env:USERDOMAIN\$env:USERNAME" -LogonType Interactive -RunLevel Limited
Register-ScheduledTask -TaskName "磐鈺停車場每日匯入" -Action $action -Trigger $trigger -Settings $settings -Principal $principal -Force
```

## 八、設定 last_run.txt
```
python -c "open(r'C:\temp\parking\last_run.txt','w',encoding='utf-8').write('2026-05-21')"
```
（填入昨天的日期，系統會從隔天開始補跑）

## 完成！
每天早上 8 點電腦開機有網路，即自動執行。
